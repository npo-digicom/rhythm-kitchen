# 作り直しレポート:食材すくいゲーム

「左から流れてくる食材を中央で切る」形から、「いろいろな動きをする食材を網ですくう」形に作り直しました。

---

## 1. 変わったところ

### 遊び方
| 前 | 今 |
|---|---|
| 左から流れてくる食材を、中央でタイミングよく切る | いろいろな方向から、違う動き方で食材が現れる |
| 「切る」ボタンを押す | 動いている食材を直接タップ → 網がすくって画面下のザルへ |
| タイミングで「きれい/大きめ」の判定 | 判定なし。にがした食材は約4秒後にまた出てくる |
| 料理は1品固定(プサリ・プラキ) | つかまえた食材から4品のうち一番近いものが決まる |
| — | 終わりにザルから煙が出て「ボン!」→ 電子レンジの「チン!」 |
| — | 食材図鑑(ブラウザに記録) |

- 点数はどこにも表示しません(料理と盛り付けを決めるためだけに、内部で数えています)。
- 食材の動きの型は6つ(ビューン/ぐるぐる/ふわふわ/ピョンピョン/ポンポン/すいー)。ピョンピョンは80拍/分の拍に合わせて1拍に1回跳ねます。
- 画面に出る食材の数は、始めは2つ、終わりに向けて4つまで少しずつ増えます。
- 最初の「はじめ!」から約90秒。残り4秒で新しい食材は出なくなり、「そこまで!」→ 煙 → 「ボン!」→「チン!」→ 完成画面、の順に進みます。

### 高齢の方向けの工夫
- タップの当たり範囲は、食材の丸より **まわり45px** 広くしています(少しずれても取れます)。
- 食材の丸は直径80〜100px。名前のラベルを下に付けています。
- 基本の文字は20px。ボタンは高さ68〜76pxで画面幅いっぱい。
- 白い丸に濃い色の太いふちで、食材どうしの見分けがつきやすいようにしています。
- 空振りのときは、責めない小さな音だけ鳴ります。
- iPhone の縦画面を最優先。パソコンでは画面の中央にスマホの形の枠で表示します。

### そのまま残したもの
- 80拍/分の拍の音(4拍ごとに少し高い音)
- iPhone の Safari で音を鳴らすための仕組み(最初のボタンを押したときにロック解除)
- 電子レンジの「チン!」
- 曲ファイル・PNG画像に後から差し替えられる作り

## 3. JSON の書き換え方

### 書き換えるときの注意(大事)
- 文字は必ず `"` (半角のダブルクォート)で囲みます。
- 項目と項目の間は `,`(半角カンマ)。**最後の項目のあとにはカンマを付けません。**
- 書き間違えると、はじまりの画面に赤い枠で「データを読み込めませんでした」と出ます。そのときは直前の変更を見直してください。
- `"_memo"` で始まる項目はメモ用です。ゲームは読みません。
- 書き換えたら、ブラウザを再読み込みしてください。

### 3-1. 食材を変える・増やす(data/ingredients.json)

`ingredients` の中に、1つの食材が `{ … }` 1つで書かれています。

```json
{ "id": "tomato", "name": "トマト", "emoji": "🍅", "color": "#D32F2F", "motion": "fuwafuwa",
  "image": "images/ingredient_tomato.png",
  "description": "赤い色はリコピン。…" }
```

| 項目 | 意味 |
|---|---|
| `id` | 食材の名札(半角英数字)。料理の材料指定で使います。**他と重ならないように** |
| `name` | 画面に出る名前 |
| `emoji` | 画像が無いときに出る絵文字 |
| `color` | 丸のふちとラベルの色(`#` + 6けた)。濃いめの色がおすすめ |
| `motion` | 動きの型(下の表から選ぶ) |
| `image` | PNG画像の場所。ファイルが無ければ絵文字が出ます |
| `description` | 図鑑で出る短い説明 |

動きの型(`motion` に書く言葉):

| 書く言葉 | 動き |
|---|---|
| `byun` | ビューン:画面を素早く横切る |
| `guruguru` | ぐるぐる:回りながらゆっくり進む |
| `fuwafuwa` | ふわふわ:上下に漂う |
| `pyonpyon` | ピョンピョン:跳ねながら進む |
| `ponpon` | ポンポン:上から落ちてきて弾みながら移動 |
| `suii` | すいー:下からゆっくり浮かんでくる |

上の `motions` の中の `seconds` は「画面にいる時間(秒)」です。大きくするとゆっくりになります。
`label`(図鑑に出る名前)と `description` も書き換えられます。

### 3-2. 料理を変える・増やす(data/dishes.json)

`dishes` に `{ … }` を1つ足すと、料理が1品増えます。

```json
{
  "id": "greek_salad",
  "name": "ギリシャサラダ",
  "subtitle": "チーズとオリーブがきいた、さっぱりサラダ",
  "emoji": ["🍅", "🥒", "🧅", "🫒", "🧀"],
  "image": "images/dish_greek_salad.png",
  "ingredients": ["tomato", "kyuri", "tamanegi", "olive", "feta"],
  "easyRecipe": {
    "title": "切って混ぜるだけ ギリシャサラダ",
    "servings": "2人分",
    "materials": ["トマト 1個", "…"],
    "steps": ["トマトときゅうりはひと口大に切る。", "…"]
  }
}
```

- `ingredients`:その料理の材料。食材の `id` を並べます。
  「どれか1つあればOK」にしたいときは `{ "label": "魚", "any": ["iwashi", "saba"] }` のように書きます。
- `emoji`:画像が無いときに、器の上に盛る絵文字。
- `image`:完成した料理の画像。無ければ器と絵文字のダミーが出ます。
  盛り付けごとに画像を変えたいときは、`"images": { "kobachi": "…png", "hitosara": "…png", "oozara": "…png" }` を足してください。
- `easyRecipe`:完成画面の「今日作れる、かんたんレシピ」。今は仮の文です。

**料理の選ばれ方**:それぞれの料理について
「材料がどれだけそろったか」(7割)+「つかまえた食材のうち、その料理に使うものの割合」(3割)
を計算し、一番高い料理になります。同じ点なら、ファイルの上に書いた料理が選ばれます。
何もつかまえなかったときは、ランダムに1品選ばれます(どれも失敗にはしません)。

**盛り付け**(`portions`):`minCount` 個以上つかまえると、その盛り付けになります。
今は 0〜9個 → 小鉢、10〜21個 → ひと皿、22個以上 → 大皿・山盛り。`message` は完成画面のひとことです。
※ `id`(kobachi / hitosara / oozara)は器の絵の形に使っているので、変えずに `label` と `message` を書き換えてください。

### 3-3. 空想レシピを変える(data/fantasy.json)

ランダムに部品を組み合わせて作ります。文の中の `{…}` は自動で置きかわります。

| 書き方 | 置きかわるもの |
|---|---|
| `{a}` `{b}` `{c}` | つかまえた食材の名前(ランダムに選ばれる) |
| `{country}` | `countries` の中の国 |
| `{form}` | `forms` の中の料理の形 |
| `{n}` | 2〜7の数字 |

- `heading`:見出し(今は「🌈 空想レシピ」)
- `notice`:見出しの下の紫の帯の文(空想であることを伝える文)
- `titlePatterns`:題名の型 / `steps`:手順(毎回4つ選ばれる)/ `finishes`:最後の手順 / `comments`:ひとこと

それぞれの `[ … ]` の中に、文を足したり消したりできます。

### 3-4. 遊び心地を変える(data/settings.json)

| 項目 | 今の値 | 意味 |
|---|---|---|
| `gameSeconds` | 90 | 遊ぶ時間(秒) |
| `bpm` | 80 | 拍の速さ(1分あたりの拍の数)。曲に合わせて変えてください |
| `beatSound` | true | 拍の音を鳴らすか(`false` で消える) |
| `bgm.file` | "" | 曲のファイル(例:`"audio/piccadilly.mp3"`) |
| `bgm.volume` | 0.8 | 曲の音量(0〜1) |
| `bgm.beatSoundWithBgm` | false | 曲を流すときも拍の音を鳴らすか |
| `speedScale` | 1.0 | 食材の速さ。0.8 にするとゆっくり、1.2 で速く |
| `maxOnScreenStart` / `maxOnScreenEnd` | 2 / 4 | 画面に同時に出る食材の数(始め/終わり) |
| `spawnEveryBeats` | 2 | 何拍ごとに新しい食材を出すか |
| `respawnDelaySec` | 4 | にがした食材がまた出てくるまでの秒数 |
| `stopSpawningBeforeEndSec` | 4 | 終わりの何秒前から新しい食材を出さないか |
| `zukanStorageKey` | … | 図鑑の記録の保存名。変えると図鑑が空から始まります |

## 4. 画像と曲の差し替え

画像は置くだけで自動で使われます(無いものは絵文字・ダミーで表示)。

| ファイル | おすすめの大きさ | 用途 |
|---|---|---|
| `images/background.jpg` | 1080×1920 | 全画面の背景 |
| `images/ingredient_<id>.png` | 512×512(背景は透明) | 食材(例:`ingredient_tomato.png`)。場所は ingredients.json の `image` で変更可 |
| `images/dish_greek_oven.png` | 1024×1024 | ギリシャのオーブン焼き |
| `images/dish_kaisendon.png` | 1024×1024 | 海鮮丼 |
| `images/dish_bibimbap.png` | 1024×1024 | 石焼ビビンバ |
| `images/dish_greek_salad.png` | 1024×1024 | ギリシャサラダ |

食材の id 一覧:iwashi, saba, ebi, tako, tomato, kyuri, tamanegi, paprika, olive, lemon, paseri, horenso, feta, gohan, tamago

**ピカデリーの曲**:`audio/` に曲を置き、settings.json の `bgm.file` に場所を書きます。
曲のテンポに合わせて `bpm` も変えてください(ピョンピョンの跳ねる速さも拍に合わせて変わります)。

## 5. 図鑑の記録

- ブラウザの localStorage に `rhythmKitchen.zukan.v1` という名前で保存しています。
- 記録の中身:食材ごとに「初めてつかまえた日」と「つかまえた回数」。
- 同じiPhone・同じブラウザなら、次に開いたときも残っています。
- 記録を消したいとき:Safari の「設定 → Safari → 詳細 → Webサイトデータ」から消すか、settings.json の `zukanStorageKey` を別の名前に変えます。

## 6. 試し方

JSON をブラウザで読み込むため、**index.html をダブルクリックで直接開くと動きません**(「データを読み込めませんでした」と出ます)。
次のどれかで開いてください。

- VS Code の拡張機能「Live Server」で index.html を開く
- ターミナルで次を実行し、ブラウザで `http://localhost:8080` を開く

  ```bash
  python3 -m http.server 8080
  ```
- GitHub Pages で公開する(公開後はそのまま動きます)

iPhone で試すときは、パソコンと iPhone を同じ Wi-Fi につなぎ、`http://(パソコンのIPアドレス):8080` を Safari で開きます。

動作確認用に、ブラウザの開発者ツールで `App.showResult({ caught: { tomato: 3, kyuri: 2 } })` と入力すると、その食材をつかまえたときの完成画面をすぐ見られます。
